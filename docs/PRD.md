## 1. 제품 개요

브라우저에서 동작하는 **경량 스프레드시트 웹 애플리케이션**이다. 사용자는 셀에 값을 입력하고, 범위·행·열·전체 시트를 선택하며, **Excel(.xlsx) 파일로보낼** 수 있다. 백엔드 없이 클라이언트만으로 동작하며, `localStorage`로 작업 내용을 유지한다.

---

## 2. 배경 및 목적

### 2.1 배경

- 스프레드시트 UI의 핵심 패턴(그리드, 좌표, 헤더 하이라이트, 데이터 수집·Export)을 웹 기술로 구현하는 과제·학습 목적이 있다.
- Export는 **SheetJS**를 이용한 `.xlsx` 생성으로 Excel·Google Sheets에서 바로 열 수 있게 한다.

### 2.2 목적

- 필수 6가지 기능을 제공한다.
- 선택 기능(행·열 조작, 자동 저장, UI 개선)과 함께 **편집 생산성**(실행 취소, 복사·붙여넣기, 범위 선택)을 높인다.
- HTML/CSS/JS 분리 및 제출용 문서를 갖춘 저장소를 유지한다.

## 4. 제품 목표 및 성공 기준

### 4.1 제품 목표

1. 설정 가능한 크기의 그리드에서 셀·범위·행·열·전체 시트를 선택할 수 있다.
2. 단일 셀 선택 시 **해당 행·열 헤더가 동시에** 강조된다.
3. 입력 데이터가 2차원 배열로 수집되고, `.xlsx`로 다운로드되어 Excel/Google Sheets에서 **셀 위치가 일치**한다.

### 4.2 성공 기준

- README 제출 체크리스트 항목 통과
- `index.html` 직접 열기 또는 정적 서버로 실행 가능
- Export 시트 **본문**은 그리드 데이터만 포함(제목 행 미포함), **파일명·시트 탭**에 시트 제목 반영

## 5. 기능 범위

### 5.1 Must Have (필수)

| ID | 기능 | 설명 |
|----|------|------|
| F-01 | 셀 그리드 렌더링 | 열 A, B, … / 행 1, 2, … 형태의 표 |
| F-02 | 셀 값 입력 | `textarea` 기반, 여러 줄 입력(Cmd/Ctrl+Enter) |
| F-03 | 포커스·선택 좌표 표시 | `Cell: C1` 또는 `Selection: A1:B3` |
| F-04 | 헤더 하이라이트 | 단일 셀 시 해당 열·행 헤더 동시 강조 |
| F-05 | 데이터 구조화 수집 | `string[][]` (`collectSpreadsheetData`) |
| F-06 | Excel Export | SheetJS로 `.xlsx` 다운로드 |

### 5.2 Should Have (선택·구현 포함)

| ID | 기능 | 설명 |
|----|------|------|
| F-07 | 행·열 추가·삭제 | 행/열 헤더 **오른클릭** 컨텍스트 메뉴 |
| F-08 | localStorage 자동 저장 | 데이터·크기·시트 제목, 300ms debounce |
| F-09 | UI 스타일 | 선택 셀·범위·헤더·Export 버튼·툴바 레이아웃 |
| F-10 | 시트 제목 | 툴바 클릭 편집, 기본 「제목없음」, Export 파일명·탭명 반영 |
| F-11 | 범위 선택 | 드래그, Shift+화살표, 행/열/코너 헤더 선택 |
| F-12 | 실행 취소·다시 실행 | 최대 100단계, Cmd/Ctrl+Z 등 |
| F-13 | 복사·붙여넣기 | TSV 복사, HTML/TSV/마크다운 표 붙여넣기, 부족 시 그리드 확장 |
| F-14 | 사용 가이드 | 툴바 모달, 기능별 설명 카드 |
| F-15 | 기본 반응형 UI | 720px/480px 이하 툴바 줄바꿈·짧은 버튼 라벨·그리드 가로 스크롤·가이드 하단 시트 |

### 5.3 Out of Scope (제외)

- 서버·DB·인증·실시간 협업
- 수식 엔진, 차트, 피벗, 다중 시트 워크북
- `.csv` 전용 Export UI(현재는 `.xlsx`만 제공)
- 모바일 터치·제스처 전용 UX(데스크톱 우선, 좁은 화면은 기본 레이아웃만 보조)

## 6. 확정된 제품 의사결정

| 항목 | 결정 |
|------|------|
| 기본 그리드 | `CONFIG.defaultRows` / `defaultCols` (기본 5×5) |
| 런타임 크기 | 헤더 컨텍스트 메뉴·붙여넣기로 확장/축소 |
| Export 형식 | SheetJS CDN, `.xlsx` |
| Export 파일명 | `{정규화된_제목}.xlsx`, 제목 없으면 `제목없음.xlsx` |
| 시트 탭명 | 제목 정규화(최대 31자), 없으면 `제목없음` |
| Export 본문 | 그리드 `data`만 (제목 행 미포함) |
| 셀 편집 | `<textarea class="cell-input">` |
| 행·열 조작 UI | 하단 버튼 없음 → **헤더 오른클릭** |
| 의존성 | 앱 로직은 Vanilla JS, Export만 SheetJS CDN |

## 7. 사용자 시나리오

### A — 셀 편집 및 좌표

1. 셀 클릭 → `Cell: B2`, B열·2행 헤더 강조
2. 선택 모드에서 Enter 또는 같은 셀 다시 클릭(드래그 없음) → 편집 모드
3. 편집 모드에서 Enter → 아래 셀로 이동

### B — Excel보내기

1. (선택) 툴바에서 시트 제목 편집
2. **Export Excel** 클릭 → `{제목}.xlsx` 다운로드
3. Excel 또는 Google Sheets에서 그리드와 동일한지 확인

### C — 표 붙여넣기

1. 외부 표 복사 후 그리드에서 Cmd/Ctrl+V
2. 범위가 그리드보다 크면 행·열 자동 확장

### D — 행·열 조작

1. 행 번호 헤더 오른클릭 → 위/아래 추가·삭제
2. 열 헤더 오른클릭 → 왼쪽/오른쪽 추가·삭제
